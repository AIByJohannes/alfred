# Alfred Ecosystem

Permanent project entry points:

- [Alfred CLI](https://github.com/AIByJohannes/alfred/tree/main/cli): Rust terminal agent and ACP runtime.
- [Alfred desktop workbench](https://github.com/AIByJohannes/alfred/tree/main/app): Gradio desktop-oriented interface.
- [Alfred Android](https://github.com/AIByJohannes/alfred-android): Android companion application.

The CLI and workbench live in this repository. The Android link remains stable even when its implementation evolves independently.
