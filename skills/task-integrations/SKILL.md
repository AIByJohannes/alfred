# Task Integrations

1. Discover the configured integration before attempting an operation.
2. Show the intended task or habit details before destructive or bulk changes.
3. Preserve external identifiers in session artifacts so future changes target the right item.
4. Confirm the resulting remote state after a create, update, completion, or deletion.
5. Report authentication or missing-integration errors directly without inventing a local substitute.
