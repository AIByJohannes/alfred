# Obsidian Vault

1. Confirm the target vault and operation before making a write.
2. Use the Obsidian CLI for search, read, create, move, and task operations instead of manipulating vault metadata directly.
3. Search for related notes before creating a duplicate.
4. Preserve Markdown links, frontmatter, and existing local conventions.
5. Summarize changed note paths and verify the requested content after writing.
